## Tổng quan dự án

### Mục tiêu
Nền tảng hỗ trợ tái hòa nhập và lập nghiệp cho lao động trung niên (35+).

### Các vai trò
- `worker` - Người lao động >35 tuổi ✅
- `enterprise` - Doanh nghiệp 🔜
- `trainer` - Trung tâm dạy nghề 🔜
- `ngo` - Tổ chức phi chính phủ 🔜
- `admin` - Quản trị ✅
